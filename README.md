# Employee Management System

A full-stack Employee Management System built using **Java, Spring Boot, MySQL, HTML, CSS, and JavaScript**.

The application provides a user-friendly dashboard for managing employee information with CRUD operations, search, department filtering, sorting, and pagination.

---

## 🚀 Features

- ✅ Add new employees
- ✅ View employee records
- ✅ Edit employee details
- ✅ Delete employees
- 🔍 Search employees by name, email, or department
- 🏢 Filter employees by department
- ↕️ Sort employees by available options
- 📄 Pagination for employee records
- 📊 Dashboard statistics
- 💾 MySQL database persistence
- 🔗 REST API integration
